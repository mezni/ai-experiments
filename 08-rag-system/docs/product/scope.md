# Product Scope

## In Scope

### Knowledge

- Markdown documents
- Text documents
- Document metadata
- Document versions
- Chunked content
- Embeddings

### Retrieval

- Vector search
- Keyword search
- Hybrid search
- Metadata filtering
- Reranking
- Context expansion

### Generation

- OpenRouter LLM provider
- Prompt construction
- Citation extraction
- Grounding checks

### Operations

- Ingestion runs
- Reindexing
- Index validation
- Evaluation
- Metrics
- Cost tracking
- Audit events
- Health checks

### API

- Health endpoint
- Readiness endpoint
- RAG query endpoint

## Out of Scope

- Authentication providers such as OAuth/OIDC
- Multi-tenancy
- Web crawling
- Autonomous agents
- Real-time document collaboration
- Distributed orchestration
- Production Kubernetes deployment

This prevents the project from growing indefinitely.
